Privacy Policy

Admob daily report — Updated October 24, 2026

Purpose and operator

This personal reporting tool is operated by shahzad16181-hub to collect advertising performance reports for the account owner.

Google data accessed

With the account owner's authorization, the tool reads Google AdMob publisher account information, reporting currency and time zone, app identifiers and names, and daily estimated advertising earnings. Google Ads spending is collected separately using Google Ads Scripts.

Use and storage

Reports are written to the owner's Google spreadsheet for advertising cost and revenue analysis. Scripts run on Google's infrastructure. This public website does not display the reports or provide access to the spreadsheet.

Sharing

The tool does not sell Google user data or use it for advertising. Reports are accessible to people granted access to the spreadsheet. Google processes data as needed to provide its APIs, Apps Script, and Sheets services.

Permissions and security

The tool uses Google authorization rather than collecting account passwords. AdMob access is read-only. Spreadsheet editing permission is used to write reports. The owner controls spreadsheet sharing and should restrict access to trusted people.

Retention and deletion

Reports remain in the spreadsheet until the owner deletes them. To stop collection, disable the scheduled triggers and Google Ads script schedule. Google account permissions can also be revoked through the account's third-party connections settings. Revoking access does not delete existing reports; delete those separately from the spreadsheet.

Google API user data

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Website hosting

This information website is hosted on GitHub Pages. GitHub may process visitor information, including IP addresses, under GitHub's Privacy Statement.

Contact

Contact the operator through the GitHub profile. Do not post account reports, passwords, or other private data in public messages.
